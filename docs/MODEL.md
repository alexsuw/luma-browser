# Model card

MLP 3 → 16 tanh → 3 linear, 115 обучаемых параметров. Вход: среднее значение яркости Rec.709, стандартное отклонение яркости, средний размах max(R,G,B)−min(R,G,B). Прозрачные пиксели исключены. Инференс реализован обычным JavaScript без тяжёлого runtime. Выход: добавочная яркость, коэффициент контраста и коэффициент насыщенности с ограничением допустимых диапазонов.

Обучение: `npm run train`, фиксированный seed 20260909, 240 000 синтетических векторов признаков и 5 000 независимых векторов валидации. Целевые значения генерирует консервативная политика экспозиции/контраста/насыщенности (формулы в scripts/train.mjs). SGD обучает реальные веса; в браузере применяется нейросеть, а не запуск формул учителя. Контроль почти монохромных изображений сохраняет насыщенность 1.

Это дистилляция эвристической политики, а не модель, обученная на экспертной ретуши. Значение RMSE в training.json измеряет воспроизведение политики, не эстетическое качество. Модель не распознаёт портреты, ночь, снег или художественный замысел; глобальная коррекция может ухудшить намеренно тёмные/светлые сцены. Интенсивность 0–100% позволяет ограничить изменение. Шум, локальная экспозиция, баланс белого, детализация и генеративная реконструкция не моделируются.

Для следующего этапа качества нужен согласованный набор пар исходник/эталон с правом обучения, разделение по исходным сценам, экспертная оценка и сравнение с тождественным преобразованием и политикой учителя. Публичные заявления о превосходстве такой модели без этих измерений не делаются.
